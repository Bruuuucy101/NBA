# 激励广告重抽

每次新挑战免费重抽一次，用完后每次重抽调用虎扑激励视频能力。完整观看且平台返回 `code === 200 && data.rewarded === true` 才重抽一次。失败不改变候选、不消耗次数。成功后刷新任务状态；刷新失败不会撤销已确认的奖励。

广告期间锁定页面按钮，避免重复请求或选秀状态变化。跨午夜作废旧选秀；站外缺少 SDK 时提示去虎扑 App，不模拟广告。候选不足时先提示，不拉起广告。新存档版本 4；旧版选秀重置，通关记录不变。

当前 chatgpt.site 仅部署了接入逻辑，没有虎扑平台注入的 ColorboxAI SDK 与活动绑定，不能播放真实广告。需在虎扑创建/绑定本游戏应用并启用“激励广告”，通过该平台提供的页面运行环境在虎扑 App 登录验证。不得手填活动 ID 或复用其他活动凭据。

测试使用受控 SDK 响应覆盖未看完、站外、成功、并发、任务状态刷新失败及存档恢复。这不代表真实广告已通过真机验收。

存档位于浏览器本地，没有服务器防篡改保障；不能把本地记录作为广告结算依据。平台奖励回调是页面正常流程授权来源，商业结算以虎扑平台为准。
