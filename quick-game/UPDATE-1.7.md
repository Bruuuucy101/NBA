# 1.7 快速比赛界面

快速比赛设置采用主客两栏、居中队徽、球队选择和纵向五名首发，底部返回主菜单与开始按钮。球队选择使用中文队名，不再显示快照战绩。比赛页增加中心标志和主菜单、独立播放控制面板、绿色快速比赛操作选中态，以及按评分分色的球探能力条。下方提供比赛数据对比和两队球员统计三个页签。

对比展示全场投篮、三分、罚球、内线与快攻得分、替补得分、最大领先、前后场篮板、助攻、抢断、盖帽、失误、犯规和控球时间。当前不提供按节对比切换。内线得分按内线倾向、冲筐、低位或挡拆战术下命中的两分球归类；快攻按快速节奏且回合不超过8秒的运动战得分归类。这些为独立模拟模型的统计口径，不是原站私有算法。

新增防守篮板与防守强度战术：卡位保护降低对手前场篮板概率，推进快攻有所取舍；积极防守提高失误概率，同时增加犯规风险。

数据更新：本地 league.json 快照，不实时联网刷新。资料抓取时间 2026-11-19 08:45 北京时间。维护者可运行同步与构建脚本更新快照，但截图总评和六项能力仍优先固定引用。每日挑战按北京时间更换对手，比赛内统计随模拟更新。本次没有执行外部数据同步。

验证：39项原生测试、快速比赛和每日挑战DOM操作流程通过。未进行像素级浏览器视觉核对。
