# 1.8 每日资料更新与首发排序

Codex 已建立每天北京时间08:00的本地自动任务，运行 scripts/update-daily.mjs；此任务依赖本地电脑、Codex调度环境和网络可用，不是云服务器后台任务。失败时通知，保留旧数据。本次已验证更新保护逻辑，但未执行一次完整的外网抓取；下一次计划任务负责新数据同步。打开网页本身不会自动拉取外部API，更新后刷新页面加载新快照。

同步在临时目录运行，要求30队及完整资料；固定截图来源的球员总评、能力、技能和位置。拒绝丢失截图球员的结果。主数据使用临时文件重命名替换，避免读到未完成写入的数据。源截图ratings.txt不改变。同一天成功过的任务跳过；维护者可用 --force 强制更新。

快速比赛以场均时间优先匹配控卫、分卫、小前锋、大前锋、中锋，预览和开场首发一致。主菜单按钮改成浅色底深色字。每日挑战首页的球员姓名不可点击，不再打开档案。

挑战可以胜利：最近540场策略模拟的样本胜率为27.8%、37.2%、36.1%；这不是固定玩家胜率，也没有强制失败逻辑。

验证：41项原生测试和两套DOM流程通过；30队首发均匹配位置；更新保护测试确认场均数据和战绩可变、截图评分不变、不完整资料拒绝发布。未进行像素级浏览器检查。
