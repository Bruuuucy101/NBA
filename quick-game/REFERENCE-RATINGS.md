# 原站截图评分

来源：用户在本次对话提供的30张截图，按上传顺序编号1–30。每张10名球员，共300条。附件临时文件目前无法从本机读取，因此未复制图片；录入依据为对话中可见的图片，未声称完成OCR校验。

`data/reference/ratings.txt` 是人工逐项录入的源表；字段顺序为图片编号、英文名、球员位置，以及内线进攻、外线投射、组织、篮板、内线防守、外线防守、总评。位置取姓名下方球员徽标，不取最左侧阵容槽位。`ratings.json` 是同表的结构化输出。

300名截图球员的总评和六项能力直接采用截图，不进行重新排名或统一加分。294名与原有虎扑球员匹配，6名新建为截图补充球员：小凯文-波特、朗尼-沃克四世、特雷-考夫曼-伦、塔马尔-贝茨、贾马里昂-夏普、海伍德-海史密斯。后六人的真实归属未确认，不插入真实球队；场均数据保留为空，可参加每日选秀并在数据库中查询。

原有525名球员全部保留，另有231名未出现在截图中，按以下固定规则补充估算：

1. 以旧建模的内线、外线、组织、篮板、两项防守和总评作为七维特征，各维除以20后计算欧氏距离。
2. 在截图的同角色球员中选8名最近邻。角色分为后卫、锋线和中锋；截图角色按球员位置徽标确定。
3. 邻居权重为 `1/(0.25+距离)^2`。每项取截图值的加权均值，再加上自身旧模型与邻居旧模型均值差的35%；总评分差使用60%。
4. 四舍五入，能力限制40–99，总评限制60–95。缺数据、小样本者标记低置信度。不会用补充规则覆盖已有截图值。

总球员库为531名。姓名匹配去除重音、标点和常见后缀，Alex Sarr显式对应Alexandre Sarr；不使用模糊姓名自动合并。重复或未处理的身份会中止构建。球队名单继续采用已有虎扑资料，不把截图的游戏阵容当成真实转会。

总评、六项能力在球员档案显示；来源标记为“原站截图”或“补充估算”。六项能力实际进入比赛：两分使用内线进攻/内线防守，三分使用外线投射/外线防守；综合防守取两项防守平均，体能沿用原模型（仅截图补充球员为70），后两者不是截图提供。

重建命令：`npm run build:data`，输出来源覆盖与逐个估算邻居记录到`data/reference/coverage.json`。重建不会丢失截图覆盖。评分版本变化会重置未完成的每日选秀，已通关日期保留。

验证：300条录入值与运行数据逐项一致、重复身份拒绝、531实体与原30队名单完整性、估算范围和确定性均有测试。另执行快速比赛/每日挑战DOM完整流程及真实阵容批量模拟；最新结果见data下的验证JSON。测试证明录入表到游戏的数值一致，不等同于独立复核所有截图转录。
