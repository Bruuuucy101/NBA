## 运行

需要 Node.js 20 或以上。无需安装运行依赖。

```sh
npm start
```

打开 http://127.0.0.1:8478 。macOS 也可双击 `启动游戏.command`。如 8478 已被其他程序使用，运行 `PORT=8479 npm start`。服务仅监听本机，不向外网发布。

## 已有功能

- 新增每日挑战：固定每日对手、十轮三选一组队、断点恢复、每天一次胜利计入本机连续通关记录。规则见 `DAILY-CHALLENGE.md`。
- 评分 v2：位置权重、保守投射估计与联盟分位总评；最高98、平均约74，完整说明见 `MODEL.md`。

- 从 NBA 全部 30 队中选择主客队，完整名单、球员档案和能力说明。
- 四节 12 分钟、5 分钟加时；逐回合模拟、暂停、继续、1/4/12 倍播放与立即结算。
- 双方进攻战术、主控、节奏、出手倾向、防守、8/10/12 人轮换；暂停时修改，下回合生效。
- 比分走势、实况、分节比分、完整球员技术统计、再战与更换球队。
- 种子可复现。同一初始状态和相同回合时点的战术操作产生相同结果；速度不改变算法。再战使用下一个种子。
- 保存主客队与种子偏好，不恢复比赛中途进度。资料缺失、缓存损坏、无头像均有处理。

## 数据与更新

- `data/raw/`：逐请求原始响应、来源 URL 与原始抓取时间。
- `data/snapshot.json`：关联球队、阵容、球员档案和薪资表的原始资料快照。
- `h5/data/league.json`：页面使用的完整球员实体、球队名单和游戏能力值。
- `h5/data/completeness.json`：覆盖数量、缺失值、失败请求和名单异常。
- `DATA-REPORT.md`：本次数据覆盖及限制。

```sh
npm run sync
# 强制重新获取所有资料（仍按串行节流和有限重试执行）
node scripts/sync.mjs --refresh
npm run build:data
```

普通同步在 24 小时内复用逐请求缓存以便断点续传；缓存时间过期后重拉。快照时间从原始响应抓取时间计算，不冒充当前运行时间。目标赛季固定 2026-2027，不静默降级为其他赛季。拉取需要网络、curl，可能耗时数分钟。原始接口不出现在页面请求中；前端只读取已生成数据。

**覆盖范围**为抓取时 30 支球队当前阵容并集，不包括不在当前球队名单内的自由球员和赛季早期已离队球员。完整性只表示成功覆盖接口返回名单，无法证明上游未遗漏合同/双向球员。

**赛季限制**：常规赛 standings 请求明确选择 2026-2027；阵容、球员资料接口不接受 season 参数，因此当前阵容与场均字段来自接口当前状态，无法逐项独立核实统计赛季。报告将 `statSeasonVerified` 标为 false。

## 建模与模拟

详见 `MODEL.md`。统计缺失保留 null，小样本向固定先验收缩。游戏能力值属于估算，尤其防守与体能没有实测追踪数据；不冒充官方评级。薪资保存于原始资料，不参与能力评分。伤停标记不禁用球员，本模式全员健康出场。

预计首发按场均时间排序，缺失时间排后；不是经过位置优化的官方首发。完整名单保留，默认 10 人轮换。六犯球员从下一次轮换立即替换；若全队不足五名未六犯球员，启用人数不足例外（简化规则，未额外罚技术罚球）。不包含伤病生成、挑战判罚、暂停次数、24 秒违例、故意犯规或真实场上空间模型。

## 文件结构

- `h5/daily.mjs`、`daily-view.mjs`：每日对手、选秀、记录与页面。
- `h5/engine.mjs`：独立确定性比赛状态机。
- `h5/model.mjs`：统计解析、能力估计、完整性检查和共享阵容排序。
- `h5/app.mjs`、`style.css`、`index.html`：中文界面。
- `scripts/`：数据同步、构建、验证、本地服务。
- `tests/`：数据、API、模拟回归测试和 DOM 操作测试。

无云部署、登录、广告或实时联网功能。头像与队徽使用来源图片 URL，离线/加载失败会显示占位图；核心数据和游戏仍可运行。
