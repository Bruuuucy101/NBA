# Ratings v2 and Daily Challenge implementation plan
User explicitly requested rating corrections and adding Daily Challenge. Existing direct execution and local-only delivery authorization persists. Use existing checkout, no new services.
## Design
Ratings: use minute exposure rather than games alone for sample shrinkage, role-aware priors/overall weights, cap uncertain percentage extremes when attempts unavailable, map composite league percentile to 60–98 overall with unknown-minute cap. Skill components affect simulation; overall is calibrated display/ranking, not a direct blanket hit-rate bonus. Document formulas and uncertainty.
Daily: screenshot-inspired pink panel with 5 opponent starters, Shanghai date and local streak. Deterministic date + dataset-version opponent (5 starter slots PG/SG/SF/PF/C, five backups); positions are inferred from coarse positions/height and assist rate, labeled estimated. Ten rounds; 3 deterministic choices per round from current league excluding opponent and prior picks, first 5 slot-constrained, next 5 backups. Choices no reroll on reload. Same-day attempts repeatable; first win counts once per day, losses never add a day. Gaps break streak; local storage is not anti-cheat. Draft persisted, game replay starts at beginning; midnight blocks old-day new starts, in-progress match may finish but is recorded for original date. CPU tactics locked.
